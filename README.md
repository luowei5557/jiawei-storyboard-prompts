# 嘉伟漫剧分镜提示词

把中文剧本拆成镜头表、关键帧图片提示词和逐段视频提示词的 Codex Skill。也可以叫“嘉伟漫剧视频提示词”。

适合真人漫剧、AI 短剧的分镜准备，重点处理人物调度、对白时长、递物与持物、光影统一和跨段衔接。输出的是可复制的文本方案；生图和生视频由你选择的模型执行。

## 能做什么

| 你给的材料 | 输出 |
|---|---|
| 一场或一集剧本 | 请求范围内的完整镜头表、关键帧提示词、逐段视频提示词 |
| 已有分镜或一个片段想法 | 直接可复制的单段提示词 |
| 视频末帧、已生成片段或明确的末态描述 | 从实际状态继续的下一段提示词 |
| 指定镜头和修改要求 | 局部修订及必要的相邻衔接调整 |

它会保留原对白和剧情顺序，根据对白与动作安排时长，不强制每段 15 秒或固定镜头数。参考素材没有提供时会标明缺项，先完成规划草案。

## 安装到 Codex

将下面这段话复制到 Codex：

```text
请使用 skill-installer，把 https://github.com/luowei5557/jiawei-storyboard-prompts
仓库根目录作为个人 Skill 安装，名称为 jiawei-storyboard-prompts。
保留 agents、references、licenses、SOURCES.md 和 LICENSE。
如果已经安装，请先比较版本，不要直接覆盖我修改过的文件。
```

也可以下载仓库 ZIP，解压后把整个文件夹命名为 `jiawei-storyboard-prompts`，放进当前 Codex 配置使用的个人技能目录。请保留目录结构，不能只复制一个 `SKILL.md`。不同 Codex 版本的技能目录可能不同，可让 Codex 先确认自己的目录。

安装后在新对话中使用。如果技能列表还没刷新，重新打开对话或重启 Codex 后再检查。没有可用的 `skill-installer` 时使用手动方式。

## 怎么调用

直接说中文：

> 用嘉伟漫剧分镜提示词，把下面这场戏拆成分镜、关键帧和视频提示词。

或明确指定：

```text
$jiawei-storyboard-prompts
制作形式：真人写实漫剧
成片比例：16:9
目标平台：暂未确定，先写通用提示词
声音：保留对白和环境声，不加配乐
参考素材：后续补充角色和场景图
剧本：[粘贴你的剧本]
```

已有资料会直接沿用，不必每次填写所有字段。只想要一条提示词时，可以直接说“只输出这一段的视频提示词”。

续接时可以这样说：

```text
用嘉伟漫剧分镜提示词继续下一段。
这是上一段的末帧：[附图]
实际末态：男主已经用左手拿到文件夹，女主双手空着。
下一步：他把文件夹放到桌上，说“你还知道什么？”
只给我一段能复制的视频提示词。
```

## 人物卡与视频画幅

支持使用 3:4 人物资产卡作为身份和服装参考：上方正脸、侧脸，下方身体三视图，左上角角色名及造型名。

人物卡的 3:4 不会自动变成成片比例。生成电影画面时只取需要的角色和视图，不把多视图排版、角色名字或重复人形带入镜头。这个 Skill 负责使用人物卡做分镜参考，人物资产卡本身的生成提示词由对应资产技能负责。

## 当前版本与检查范围

版本 `1.0.0`。已检查技能元数据、目录结构、内部引用，并用整场拆镜与实际末态续接两类文本案例做过行为测试。尚未用该版本进行生图或生视频实测，提示词不保证模型每次准确执行。

平台参数以你实际使用的模型版本为准；先写通用提示词，再按需要适配。当前 Skill 本身不包含 API、密钥、生成脚本或模型订阅。
